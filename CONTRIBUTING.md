# Contributing

Issues and pull requests are welcome.

- Open an issue before starting large changes.
- Keep each pull request to one change, and run `uv run python manage.py check` and the tests first.
- Never commit credentials, personal data or real survey data. Use synthetic data in tests and examples.
- Report security problems through [SECURITY.md](SECURITY.md), not in a public issue.

By contributing, you agree that your contribution is licensed under AGPL-3.0-only, the licence of this project. This project follows a [code of conduct](CODE_OF_CONDUCT.md).
